# Embervale

An HD-2D action RPG that runs in your browser: pixel-art heroes in a lit 3D world, seven classes, bosses, pets, loot and a speedrun mode.

**Play:** https://toltecs101.github.io/embervale/

Works on PC and phones. Your progress saves in your browser.

Built as a single HTML file (plain JavaScript and WebGL, no engine or libraries), vibe coded with Opus 5.5 and Astra.
